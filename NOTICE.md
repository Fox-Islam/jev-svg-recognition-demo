# Sample SVGs

The files in `samples/` are copied unchanged from the sources below, through
[jev-svg-recognition](https://github.com/Fox-Islam/jev-svg-recognition), and keep their licences. The code in this
repository is MIT; these files are not.

| Samples | Source | Licence |
|---|---|---|
| `objects-*.svg` | [Rapidata/svg-benchmark](https://huggingface.co/datasets/Rapidata/svg-benchmark): SVGs drawn by LLMs for its prompts | prompts CC BY 4.0; each SVG falls under the terms of the model provider that generated it, named in `samples/index.json` |
| `emoji-*.svg` from OpenMoji | [OpenMoji](https://openmoji.org) 17.0.0 | CC BY-SA 4.0 |
| `emoji-*.svg` from Twemoji | [jdecked/twemoji](https://github.com/jdecked/twemoji) 17.0.3 | graphics CC BY 4.0 |
| `emoji-*.svg` from Fluent | [Fluent Emoji](https://github.com/microsoft/fluentui-emoji), flat style, via `@lobehub/fluent-emoji-flat` 1.1.0 | MIT |
| `emoji-*.svg` from Noto | [Noto Emoji](https://github.com/googlefonts/noto-emoji) `2D/svg` at `e20cbc2bbec1` | Apache 2.0 |

`samples/index.json` gives each file's source set or generating model.
